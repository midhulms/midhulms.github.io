Flagship Project

Agentic Cost Analyzer

A routing layer that sits in front of an LLM call and determines, per prompt, whether a frontier model is required or whether a lower-cost model can perform the same task. Every routing decision, token count, and cost figure is logged and displayed on a live dashboard rather than estimated after the fact.

The system scores prompt complexity from structural signals (length, code fences, planning language), routes to one of six agent personas, and dispatches a live call through OpenAI, Anthropic, or Hugging Face’s free inference tier. Costs are tracked per account using Prometheus and Grafana metrics.
